**Jetsnack – Mobile UI Automation**

1. Automation tool: Maestro
2. Platform: Android
3. Application: Jetsnack
4. Application ID: com.example.jetsnack

**How to Run the Test**

1. Install Android Studio and start an Android Emulator.
2. Install and open Maestro Studio.
3. Connect the running Android Emulator to Maestro Studio.
4. Open the open-filters.yaml file.
5. Click Run Test to execute the automation.
6. Check the test results in Maestro Studio.

**What I learned?**

1. I learned how and what to use to be able to make one automation test
